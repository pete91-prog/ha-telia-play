# Telia Play

Choose which **streaming services** are enabled on your Telia Play subscription, using the **TV points** already included (Valgmeny).

## Install

Use HACS → add this repository as a custom **Integration**, then download **Telia Play** and restart Home Assistant.

## Setup

Settings → Devices & services → Add integration → **Telia Play**. Country **Norway**, then the same email (or mobile) and password as on teliaplay.no. If that is rejected, approve the TV code on your phone.
